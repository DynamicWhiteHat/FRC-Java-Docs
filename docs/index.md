# Welcome To The Guide To FRC Java

This site serves as a starting point for learning to code for FRC.

Make your way through the pages to gain a foundation for programming on the team.

## Getting Started

If you're new, start with the [Getting Started Guide](gettingStarted.md) to set up your tools and environment.

## Table of Contents

- [Java Basics](introToJava/whyJava.md): the Java you need, with code you can run and edit right on the page.
- [FRC-Specific Programming](frcSpecifics/frcProgramming.md): how a robot program runs and the Java that shows up in every project.
    - [Subsystems](frcSpecifics/subsystems.md): a mechanism split into IO classes and a state machine.
    - [RobotContainer](frcSpecifics/robotContainer.md): building the robot and connecting the controller.
    - [RobotState](frcSpecifics/robotState.md): the robot's brain, turning one button into the right state for every subsystem.
    - [Constants](frcSpecifics/constants.md): where every number lives, and how to tune it while the robot runs.

Most pages have live editors and practice challenges. You don't need to install anything to try them. The robot examples run in a pretend WPILib that lives in your browser.
